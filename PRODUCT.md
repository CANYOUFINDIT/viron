# Product

## Register

product

## Users

Viron serves administrators and operations engineers who manage environments, web entries, SSH hosts, and MySQL or MariaDB connections from desktop and tablet browsers. They work in dense, repeated operational workflows where fast navigation, clear system state, and trustworthy controls matter more than decorative presentation.

## Product Purpose

Viron provides one environment-centered workspace for organizing access resources and performing real SSH, SFTP, and database maintenance. Success means an administrator can find the correct environment or connection quickly, understand its state, open the appropriate workbench, and complete sensitive operations without ambiguity or unnecessary context switching.

## Brand Personality

Reliable, restrained, efficient. The interface should feel technically capable and calm, with concise language and deliberate interaction feedback.

## Anti-references

- Marketing-site navigation with oversized display typography, full-screen promotional panels, or decorative choreography.
- Consumer-style interfaces that trade information density for large cards and excessive whitespace.
- Novel controls that hide standard navigation, system status, or operational actions.
- Visual effects that compete with terminals, database tools, tables, and other task-focused surfaces.

## Design Principles

- Keep the operator in context: primary navigation and system controls stay predictable and immediately reachable.
- Make state legible: active routes, system health, selection, loading, errors, and destructive actions must be visually distinct.
- Preserve useful density: compact controls and structured information should support scanning without becoming cramped.
- Earn every motion: animation explains state changes and hierarchy, then gets out of the way.
- Prefer familiar operations: standard browser, keyboard, navigation, table, and workbench behaviors take priority over novelty.

## Accessibility & Inclusion

Target WCAG 2.1 AA contrast and keyboard operation for core workflows. Interactive controls require visible focus states and accessible names. Navigation must remain usable when collapsed, must not rely on color alone, and must provide a reduced-motion path for users who request it. Layouts should remain coherent on desktop and tablet widths, with narrow screens retaining access to essential navigation and controls.
