# SSH 连接能力

资源池与工作台连接编辑器提供相同的认证、网络路径和协议配置。桌面直连和服务端连接使用同一组 SSH 协议选项；数据库和 Redis 的 SSH Tunnel 也会复用所选 SSH 连接的代理与跳板链。

## 认证

| 方式 | 适用配置 |
| --- | --- |
| 密码 | 用户名与密码 |
| SSH 密钥 | 工作空间托管密钥；编辑旧连接时可继续使用原内嵌私钥 |
| 键盘交互 | 以保存的密码回答 SSH keyboard-interactive 提示；当前不提供人工输入多步 OTP 的交互流程 |
| SSH Agent | 使用执行端 Agent 中已经解锁的密钥，连接无需保存私钥 |

SSH Agent 的执行位置与连接模式一致：桌面直连使用本机 Agent，服务端连接使用服务器上的 Agent。Socket 留空时，macOS/Linux 读取 `SSH_AUTH_SOCK`，Windows 使用 Pageant，也可以显式配置 Agent Socket。选择 Agent 认证时不会自动回退到连接中历史保存的密码。

“转发 SSH Agent”可独立开启，用于在远程会话中访问执行端 Agent；启用时也需要执行端存在可用 Agent。

## 网络路径

- **直连**：直接建立到目标主机的 SSH 连接。
- **HTTP CONNECT**：先向 HTTP 代理申请 TCP 隧道，支持可选的 Basic 代理认证。
- **SOCKS5**：支持无认证、用户名/密码认证，以及域名、IPv4、IPv6 目标。域名交由代理解析。
- **ProxyJump**：目标连接引用已有 SSH 连接作为跳板，并沿用该连接自身的完整跳板链，最多 8 跳。循环引用会被拒绝。

例如，目标引用跳板 B，B 引用跳板 A，A 使用 SOCKS5 代理，则实际顺序为：

```text
执行端 → SOCKS5 代理 → 跳板 A → 跳板 B → 目标主机
```

同一条 SSH 连接不能同时设置出站代理和 ProxyJump。需要组合时，将代理设置在最外层跳板机上。跳板链必须属于同一工作空间。

代理密码以加密凭据保存，不放入公开连接选项或列表响应。重新编辑时，密码留空会沿用原值。

## 协议与兼容性

- 连接超时：1–120 秒。代理协商和每一跳 SSH 握手分别受超时限制；整条多跳链的总时长可能更长。
- IP 版本：自动、IPv4、IPv6。出站代理场景下控制执行端连接代理的 IP 版本；跳板转发目标由跳板机解析。
- 压缩：开启后优先协商 SSH 压缩。
- 算法策略：安全默认值、现代算法、兼容旧主机。兼容模式显式补充部分旧算法，用于无法升级的设备。
- 保活、终端类型和主机密钥 SHA-256 固定继续可用。

## 后续能力范围

本批完成认证与连接链路扩展。独立管理的本地/远程/动态端口转发、人工多步 MFA、会话模板继承、自定义逐项算法排序等尚未在本批实现；不应把当前版本描述为已完整覆盖 Xshell 或 SecureCRT 的全部会话能力。
