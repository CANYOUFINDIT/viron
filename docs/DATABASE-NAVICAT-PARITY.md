# 数据库工作台 Navicat 对齐基准

Viron 数据库工作台以本机 **Navicat Premium 17.1.7 Build 229（macOS）** 为功能与交互基准。颜色、字体和图标继续使用 Viron 主题体系；功能按钮的位置、顺序、分组、下拉层级、启用条件和操作语义按 Navicat 对齐。

## 对齐边界

- Navicat 同名动作必须执行同等语义，不能由 Viron 的其他能力代替。
- Viron 扩展能力放在独立 `工具` 菜单或产品原有资源页，不插入 Navicat 动作组内部。
- 没有完整执行路径或尚未达到交付标准的能力隐藏入口；已经实现但因连接、选择、任务状态或权限不足而暂不可用的动作保留并置灰。
- 不要求复刻 Navicat 的颜色、字体、图标造型和像素样式。
- Web 无法直接调用 Finder 或外部编辑器时，使用下载文件这一平台等价行为；macOS App 使用本机文件和 Finder 工作流。
- 涉及中心化权限、凭据和审计的动作继续经过 Viron 服务端或桌面可信执行层，不把明文凭据暴露给 Renderer。

## 当前交付边界

当前数据库交互对齐以三项高频能力为完成边界：

- 表设计器覆盖 Navicat MySQL/MariaDB 的高级字段、索引和表选项，并支持读取和保存已有表差异。
- 表配置文件保存、加载和管理当前筛选、排序、列顺序、列宽、隐藏列、分页大小及网格/表单模式。
- SQL 编辑器提供 Navicat 风格的上下文代码补全，包括关键字、数据库、表、视图、字段类型、表别名字段、函数、存储过程和查询参数。

完整逐列数据分析、可视化查询创建工具、自动运行、模型和 BI 的深度编辑器对齐属于后续范围，不作为当前完成条件。

## 当前功能矩阵

| 区域 | 当前实现 |
|---|---|
| 全局工具栏 | 按连接、新建查询、表、视图、函数、用户、事件、查询、备份、导航窗格、信息窗格排列；连接、表、查询和备份使用对应下拉菜单；自动运行、模型和 BI 在完整交付前隐藏 |
| 统一导航树 | 连接组、连接、数据库、分类和对象位于同一树；单击选择、双击或 `Enter` 打开，已连接的连接块再次单击折叠或展开其数据库树，下拉按钮和右键打开连接菜单；左侧对象选择与“对象”页选择共享上下文，表导入、导出和设计等全局动作以当前选中表为准；右键只选中目标；收藏区显示对象名、连接/数据库路径与数量，“仅显示收藏”同时保留包含对象收藏的连接 |
| 连接配置文件 | 在连接编辑窗口提供新建、设为活动、复制和删除；右键菜单只负责切换；创建、切换和生命周期变更前必须关闭连接；活动配置用于默认连接 |
| 对象右键菜单 | 数据库、表、视图、函数/过程、事件、查询和备份菜单按本机 Navicat 顺序、分隔和多级层次实现，不保留无效占位动作 |
| 查询工具栏 | 保存查询对象、美化、代码段、结果上下/左右布局、专注模式、连接和数据库、运行菜单、解释，以及仅在执行期间显示的停止按钮；查询创建工具在完整关系画布工作流交付前隐藏；执行历史位于独立 `工具` 菜单 |
| SQL 编写辅助 | 根据当前连接和数据库动态读取表、视图、字段及例程元数据；`FROM/JOIN/UPDATE/INTO` 后优先提示对象，表别名或表名后的 `.` 只提示对应字段并显示字段类型和来源；同时提供 SQL 关键字、常用函数、查询参数和 Monaco 原生查找 |
| 查询执行 | 支持选中 SQL、光标当前语句和全部脚本；“遇到错误时继续”逐条执行并保留每条失败语句与后续结果；Web 和桌面本机执行契约一致 |
| 查询对象 | 支持保存、打开、设计、复制、删除、重命名、导出、外部文件、外部编辑器及 Finder 定位；SQL 收藏继续作为独立工具能力 |
| 表设计 | 新建和设计已有表均使用可视化设计器；在表数据页或选中表时可用 `Cmd/Ctrl+D` 直接进入结构编辑；除字段、索引、外键、触发器、检查、注释和 SQL 预览外，覆盖填充零、字段字符集/排序规则、二进制、列格式、存储、主键/索引前缀长度、索引排序/解析器/可见性，以及数据目录、索引目录、延迟键写入、封装键、校验和、加密、联合表和统计选项；已有表读取期间显示慢响应状态，完整结构未就绪前禁止保存，超过 45 秒进入可重试错误状态 |
| 表数据 | 工具栏和底部命令按 Navicat 排列；`Cmd/Ctrl+F` 打开只搜索当前页结果的底部查找栏并支持按列、上一个/下一个定位；漏斗入口独立编辑多条筛选与排序规则，筛选值从目标列受限读取去重建议；支持事务式待提交编辑、列管理、网格/表单、分页、导入导出、提交回滚、刷新和停止加载；表配置文件提供管理、加载、保存和另存为，并恢复多条筛选、排序及当前视图状态；已打开的数据表页签切换时保留当前数据、分页、筛选、列设置和未提交状态，不重新请求表结构或第一页数据；逐列数据分析入口在完整交付前隐藏 |
| 备份对象 | 支持新建、还原、删除、复制、重命名、提取 SQL、Finder 定位和刷新；完整备份与仅结构备份分别可达 |
| 用户与权限 | 支持数据库用户创建、编辑、删除、权限管理员，以及表、视图、函数和过程的对象权限 |
| 桌面快捷键 | App 在主进程拦截业务快捷键，设置页支持录制、清除、单项/全部恢复、撤销和保存；冲突及系统保留组合会被拒绝，`Cmd/Ctrl+Shift+W` 固定关闭窗口；Web 保持默认绑定 |
| 命令列与维护 | 提供数据库命令列、服务器重载、数据字典、数据生成、表检查/分析/优化/修复、准确行数和 SQL 转储 |
| 主题与图标 | 保留 Viron 暗色、亮色、桌面主题和 Lucide 图标体系 |

## 后续对齐范围

- 表数据分析需要补齐逐列质量、分布和统计分析；在完整交付前不展示入口。它与已经完成的表配置文件是两项独立能力。
- 查询创建工具需要补齐关系画布、可视化 Join、嵌套子查询和完整参数设计流程；在完整交付前不展示入口。SQL 编辑器上下文补全不依赖这项能力。
- 自动运行、模型和 BI 的内部工作区不作为当前产品能力交付；全局按钮、逆向模型和创建 BI 工作区入口保持隐藏，后续完整实现并验收后再开放。

## 平台保留能力

以下能力不是 Navicat 动作的替代品，继续作为独立工具或平台资源存在：

- 环境关联、连接组、连接资源池和待分配资源。
- 个人、组织、项目授权及资源复制。
- 中心化凭据、活动连接、额度和审计。
- SQL 收藏与执行历史。
- 后台任务、SQL 恢复、跨连接传输、数据同步和结构同步。
- Web、macOS/Windows 客户端、本机直连和服务端转发执行模式。

## 交互契约

- 连接单击只选中，双击或 `Enter` 才连接；连接成功后重复单击当前连接块只折叠或展开数据库树，不打开连接菜单；数据库和对象同样区分选择、打开和展开。
- 连接、数据库或对象关闭后清理对应选中和高亮；关闭数据库或连接时，同属该数据库或连接的对象页、数据页、表设计和其他子功能页必须一起关闭，不保留看似仍打开的视觉状态。
- `Cmd/Ctrl+F` 根据当前上下文进入导航搜索、对象搜索、表数据当前页查找或 Monaco 原生查找；表数据筛选与排序只从漏斗入口进入，查找不会重新请求数据库。
- Web 默认使用 `Cmd/Ctrl+N/W/S/R/Enter`；桌面 App 使用当前设备的自定义绑定，并在主进程阻止网页刷新和浏览器式关闭窗口。`Cmd/Ctrl+Shift+W` 固定关闭 App 窗口。
- 关闭未保存的查询或表设计对象时必须确认保存或放弃。
- 表数据停止会取消 Web 请求；桌面本机模式立即结束等待并禁止迟到结果覆盖当前数据。
- 配置文件连接打开时，创建、切换、复制、删除和设为活动均不可执行，并明确提示先关闭连接。

## 自动化契约

- `data-navicat-action` 标识 Navicat 原生动作；同一工具栏内的标识顺序就是验收顺序。
- `data-viron-action` 标识 Viron 扩展动作，不能占用 Navicat 动作标识或绑定同名入口。
- `tests/database-navicat-toolbar-order.test.ts` 固定当前交付的全局、配置文件、查询、表设计、表数据和用户工具栏顺序，并断言未交付入口不会出现。
- `tests/keyboard-shortcuts.test.ts` 固定跨平台组合归一化、默认与覆盖绑定、冲突、系统保留组合和显示格式。
- `tests/database-navigator-menu.test.ts` 固定右键菜单顺序、层级和启用条件。
- `tests/database-connection-profiles.test.ts` 固定配置文件加密记录、授权继承、生命周期、活动配置和关闭要求。
- `tests/database-query-execution.test.ts` 与 `tests/sql-statements.test.ts` 固定服务端/桌面继续执行、错误结果和当前语句边界。
- `tests/database-table-designer.test.ts` 固定高级字段、索引、表选项、复合主键前缀和已有表差异 SQL。
- `tests/database-table-profiles.test.ts` 固定表配置文件持久化、更新、加载状态归一化和生命周期。
- `tests/database-table-data.test.ts` 固定多条筛选与排序规则解析、参数化 SQL、字段白名单和旧单规则参数兼容。
- `tests/desktop-database-runtime.test.ts` 固定桌面本机模式的筛选建议值和多规则表数据查询与 Web 协议一致。
- `tests/sql-completion.test.ts` 固定关键字、对象上下文、表别名字段、字段类型、数据库限定符和查询参数补全。
- `npm run verify:database-navicat` 使用本地开发服务和当前 `.env` 数据库建立临时个人连接，真实验证单击/双击、连接状态、数据库展开、表名与别名字段补全、查询执行、Monaco 查找、表数据当前页查找、筛选建议值、多规则排序、表配置文件、表设计高级控件和备份页；脚本无论成功或失败都会删除临时连接及其配置文件。
- 交付前必须对本机 Navicat、Viron Web 和打包后的 Viron App 执行真实操作对照；源码顺序或构建成功不能单独作为完成依据。
